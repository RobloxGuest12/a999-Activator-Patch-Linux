# a999-Activator-Patch-Linux
Ported ImagineApple's A999 Activator Patch to Linux, Nothing Added.

### Running the Script
```bash
chmod +x ./a999ap-Linux.sh
./a999ap-Linux.sh
```
If it shows
```bash
./a999ap-Linux.sh: 61: [[: not found
./a999ap-Linux.sh: 120: Syntax error: "(" unexpected (expecting "}")
```
Then run
```bash
bash ./a999ap-Linux.sh
```
